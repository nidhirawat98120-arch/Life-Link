# Life-Link | Organ Donation Platform

A frontend web project designed to provide information about organ donation and connect donors, patients, and hospitals.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Multi-page website navigation
- Donor registration interface
- Organ request interface
- Hospital information section
- User-friendly website layout
