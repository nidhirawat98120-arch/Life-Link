About Your Dashboard

This dashboard demonstrates how a web application can display user information, activity statistics and quick actions in one place.

User information is stored locally in the browser using JavaScript LocalStorage for demonstration purposes.

⚠ Student Project: This dashboard is a frontend demonstration. It does not connect to real patients, donors, hospitals or medical databases.
